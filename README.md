# ぴったん — かんたん日程調整

「トントン」のような日程調整サイトです。知り合い同士で何度でも使えます。

- **画面（フロント）**: GitHub Pages（`docs/` フォルダ）
- **データ保存（サーバー）**: Google Apps Script ＋ Google スプレッドシート（あなたの Google ドライブに保存）
- 費用はかかりません。参加者の登録・ログインも不要です。

## できること

| 幹事 | 参加者 |
|---|---|
| カレンダーをタップして候補日を選ぶ（時間帯の指定・1日に複数枠・自由入力も可） | URLを開いて名前と ○△× を入力 |
| 参加者用URLをコピー／LINE・メールで共有 | コメントを書く |
| 集計表で ○ が多い日を確認（最多の日をハイライト、○が多い順に並べ替え） | 名前をタップして回答を修正・削除 |
| 日程を「決定」→ 全員のページに表示、Googleカレンダー追加・.ics | 決定した日程をカレンダーに追加 |
| 候補の編集、締切日設定、受付終了／再開、削除 | |

幹事用の操作は **幹事用URL**（作成時に表示）を開いた端末でできます。

## 初回セットアップ（5分・1回だけ）

1. https://script.google.com/ を開き「新しいプロジェクト」を作成
2. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の内容をすべて貼り付けて保存（💾）
3. 上部の関数選択で `setup` を選び「実行」→ 権限の確認画面で自分のアカウントを選び「許可」
   （「Google はこのアプリを確認していません」と出たら「詳細」→「（安全ではないページ）に移動」）
   → ドライブに「日程調整データ（ぴったん）」というスプレッドシートが作られます
4. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選択
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   →「デプロイ」→ 表示された **ウェブアプリのURL（…/exec で終わる）** をコピー
5. `docs/js/config.js` の `apiUrl: ''` にそのURLを入れて GitHub に反映
   （GitHub のサイト上でファイルを開き、鉛筆アイコンで編集→Commit でもOK）

`apiUrl` が空のときは「デモモード」（そのブラウザ内だけで保存）で動きます。

### サーバー側のコードを更新したとき

Apps Script に新しい `Code.gs` を貼り付け →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。
（URLは変わりません）

## データについて

- 回答や候補は、あなたの Google ドライブのスプレッドシートに保存されます（直接見ることもできます）。
- 参加者用URLを知っている人は誰でも閲覧・回答できます（トントン等と同じ方式）。知り合いの範囲で共有してください。
- 幹事用URLは推測困難なランダム文字列です。他の人に送らないでください。

## 開発メモ

- サーバーロジックは `docs/js/core.js` に一本化（デモモードでもブラウザで同じコードが動く）。
  `node tools/build-gas.js` で `docs/js/core.js` + `gas/store.gs.js` → `gas/Code.gs` を生成。
- テスト: `node test/core.test.js`（スプレッドシートをスタブにして Code.gs 全体を検証）
